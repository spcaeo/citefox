# Getting help with CiteFox

CiteFox is free and made by a small team at Space-O Technologies. There is no paid support,
but we read everything.

1. **Read the docs.** Every screen and report has a short help page:
   <https://spcaeo.github.io/citefox/docs/>. In the app, the **Guide** and **Ask** buttons in
   the top bar, and **Ctrl K** (⌘K on a Mac), find the same help.
2. **Check the FAQ.** Install warnings, costs, privacy and supported engines:
   [README › FAQ](README.md#faq).
3. **Ask in Discussions.** How-to questions, ideas and show-and-tell:
   <https://github.com/spcaeo/citefox/discussions>.
4. **Report a bug.** Use the bug form in [Issues](https://github.com/spcaeo/citefox/issues/new/choose).
   Attach `logs/citefox.log` from the CiteFox data folder; keys and prompt text are redacted
   in it. Never paste API keys, passwords or webhook links.
5. **Security problems** go privately, as [SECURITY.md](SECURITY.md) describes.

Anything else, including sponsorship: **getcitifox@gmail.com**.
