## How to open it

Use any of these:

- **Help › Report a problem…** in the menu bar.
- **Settings › App settings › Data & about › Report a problem…**
- **Report this** next to a failed check on a question's page.

It opens a drawer. The link in the address bar opens the same drawer again.

## What you see

The drawer shows the exact text that would be shared. CiteFox sends nothing by itself.

- **What happened?** An optional note. A sentence or two helps a lot.
- **Include my question texts.** Off by default. Off means a failed check shows the reason only, never what you asked.
- **The report.** Scroll it and read it before you share it.

## Five ways to share it

- **Send to CiteFox.** The easiest way. Tick the line that says you understand the report is sent to the CiteFox team, then click. You get a reference like CF-7K2M9Q. Please quote it if you write to us. If it cannot send, nothing is lost: save the report as a file and email it.
- **Copy report.** Copies the text. Paste it anywhere.
- **Save as file…** Saves a text file you can attach to a message.
- **Email it to us.** Copies the report, then opens a short email to getcitifox@gmail.com. Paste the report into the email.
- **Open a GitHub issue.** Copies the report, then opens a new issue. Paste the report into it. A GitHub issue is public, so email is the private way.

A link cannot carry a whole report, which is why email and GitHub start with a short message and ask you to paste the rest.

## What the report holds

- The CiteFox version and build, your computer type, language and time zone.
- Which AI program is set up (its file name only) and whether each kind of key is set up: yes or no.
- The latest failed checks: the engine, the reason and the time.
- The last 300 lines of the CiteFox log.

## What it never holds

- Your keys or any part of a key.
- Email addresses, IP addresses, or your user name and home folder. A path shows as `~/…`.
- Your question texts, unless you tick the box.

**Show logs folder** (in the drawer and in the Help menu) opens the folder with the full log file.

## Common questions

### Does CiteFox send my report by itself?

No. It only sends, copies, saves or opens a message when you press a button. Send to CiteFox also needs your tick on the consent line.

### What if Send to CiteFox does not work?

Your report stays in the drawer. Use **Save as file…** or **Email it to us**.

### Why do most of my questions say Check failed?

Open one question and read the reason under it. Then use **Report this** to share it with us.

### Can I see the report before I share it?

Yes. The drawer shows the full text first. What you read is what is copied, saved or pasted.

### Where is the log file?

Use **Show logs folder**. The file is named citefox.log.
