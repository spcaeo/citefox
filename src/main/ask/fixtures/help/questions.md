# Questions

## How do I set a target page?

Open the question, then use **Set target page** and pick Primary. The Right page column then shows whether the AI Overview cites it.

## What should I fix first?

Start with questions where an AI Overview shows but your page is Not cited, and a rival is cited instead. Open **Get fix brief** on the row.
