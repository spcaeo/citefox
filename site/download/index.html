Opening CiteFox the first time

CiteFox is not signed with a paid certificate yet, so your computer asks once before the first start. This is expected. You can check every file against its SHA-256 below.

Skip the warning: install with one command. On a Mac or Linux, paste this into Terminal. It downloads the latest release from GitHub, checks it against its SHA-256 and installs it, so your computer does not ask first. curl -fsSL https://spcaeo.github.io/citefox/install.sh | bash Read the script first if you like: install.sh.

Mac

  1. Open the downloaded .dmg and drag CiteFox to Applications.
  2. Open CiteFox once. macOS says it could not verify the app. Click Done.
  3. Go to System Settings › Privacy & Security, scroll to “CiteFox was blocked…”, click Open Anyway and enter your password.
  4. Or run one command in Terminal: xattr -dr com.apple.quarantine /Applications/CiteFox.app

On macOS 14 or older, right-click CiteFox in Applications and choose Open also works. macOS 15 removed that shortcut.

After an update macOS may ask once to let CiteFox read its saved keys. Click Always Allow.

Windows

  1. Run the downloaded installer.
  2. If you see “Windows protected your PC”, click More info, then Run anyway.
  3. CiteFox installs for you only (no admin needed) and adds a Start menu and desktop shortcut.

Linux

  1. AppImage: allow it to run (Properties › Allow executing, or chmod +x CiteFox-*.AppImage) and open it.
  2. Ubuntu and Debian: install the .deb with sudo apt install ./CiteFox-*.deb
