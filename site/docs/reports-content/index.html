Content plan report: pages to write or fix first

The pages to write or fix first, for a writer.

What it shows

The Content plan answers "What should we write next?". It reads one check.

Tabs:

  • Plan: the pages to write and the pages to fix, biggest first.
  • Topics: which topics skip you.
  • Answer shape: how the AI answers are built (lists, steps, tables), so your page can match.
  • Sources: the sites the answers trust.
  • How we measured.

Common questions

How is it different from Fixes › What to fix?

Same idea, made to hand to a writer or a client. Fixes is where you work and log changes.

Can I download the plan as a table?

Yes. Use the download icon and pick Content plan (CSV).
